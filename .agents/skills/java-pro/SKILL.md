# Java Pro Skill Guide

## Best Practices
1. **Spring Boot 3 & Java 17+ Capabilities**: Use Records, sealed classes, Pattern Matching, pattern-based validation, and clean Spring Bean injection.
2. **REST Controller Guidelines**: Use `@Valid` DTOs, uniform ResponseEntity responses, precise HTTP status codes, and global exception handlers (`@RestControllerAdvice`).
3. **Immutability & Safety**: Keep DTOs and value objects thread-safe and immutable where possible.
4. **Clean Layer Separation**: Keep Controllers thin, Services domain-focused, and Data Access / External APIs decoupled.
